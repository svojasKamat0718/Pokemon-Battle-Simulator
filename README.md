# Pokemon Battle Simulator (Version 4)

## Overview

A C++ project focused on building a scalable Pokémon battle simulator while learning modern software architecture and software engineering practices.

## Learning Objectives

- Multi-file project organization
- Object-oriented programming
- Simple move evaluating AI
- Scalable architecture
- Git & GitHub workflow
- Clean code
